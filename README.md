# BIT 书屋 · 校园图书借阅系统

BIT 书屋是一个基于 Vue 和 openGauss 的校园图书借阅系统。读者可以按书名、作者或分类找书，查看可借册数，在线办理借还。馆员维护馆藏，数据分析员查询借阅统计，运维员查看数据库状态和备份任务。

**[打开在线书屋](http://120.46.183.209:8080/) · [浏览全部图书](http://120.46.183.209:8080/#library)**

## 第一次登录

- **想自己体验借书**：打开书屋，点右上角 **注册**。用户名以字母开头，长度为 3–32 位，可含字母、数字和下划线。设置一个至少 8 位的演示专用密码，点击 **注册并登录**，即可使用读者功能。
- **使用课程演示账号**：点右上角 **登录**，填写下表中的用户名和小组私下提供的对应密码。登录后，工作人员可从 **管理控制台** 进入相应页面。需要换角色时，点右上角用户名，选择 **切换账号**。
- **只想看书目**：可以直接点 **全部图书**。打开图书详情即可查看作者、分类和馆藏信息；附有电子书的条目还提供 PDF 或 EPUB 下载。

| 角色 | 网页用户名 | 登录后可以试什么 |
| --- | --- | --- |
| 读者 | `reader01`、`reader02` | 在 **全部图书** 借一本书，到 **我的借阅** 查看应还日期、归还图书。切换读者可对照两人的借阅记录。 |
| 馆员 | `librarian01` | 进入 **管理控制台 → 图书管理**，检索馆藏、编辑书目、上传电子书，也可管理借阅记录和公告。 |
| 数据分析员 | `analyst01` | 进入 **管理控制台 → 报表查询**，按分类和借阅状态筛选，再用相同条件导出 CSV。 |
| 运维员 | `ops1` | 在 **管理控制台** 查看数据库节点和备份任务。恢复演示使用独立验证库；主备切换需要已配置且健康的备节点。 |

## 完成一次借阅与归还

1. 以读者身份打开 **全部图书**，搜索书名或作者，选择一本可借册数大于零的书。
2. 打开详情，点 **借阅** 并确认。在 **我的借阅** 中找到同一书名，核对借出日期和应还日期。
3. 在该条记录上点 **归还** 并确认。状态变为 **已归还** 后，可以给这本书写评价。

书目代表一种书，复本代表馆藏中的具体一册。两名读者可以借走同名书的不同复本。借阅服务在同一数据库事务中更新复本状态和借阅记录；报表服务随后同步变更，因此新记录可能稍后才出现在统计里。

## 在本机运行

1. 准备 Java 21、Maven、Python 3 和可访问的 openGauss `library` 数据库。新库先按[数据库初始化说明](database/opengauss/README.md)创建角色并导入基础数据，再依次应用[馆藏扩展](database/catalog/010_web_schema.sql)、[书评与公告](database/patch/003_reviews_announcements.sql)、[书目检索函数](database/catalog/020_book_search.sql)。启用自助注册读者借还时，还需应用[自助读者角色补丁](database/patch/2026-11-24_self_registered_readers.sql)。
2. 将 [database/opengauss/env.example](database/opengauss/env.example) 复制为同目录的 `.env`，填入本机数据库地址和业务角色口令。首次初始化演示账号时，在对应的 `IAM_SEED_…_PASSWORD` 项中设置各账号的网页登录密码。
3. 在仓库根目录运行以下命令。终端显示 `Ready` 后，打开[本机书屋](http://127.0.0.1:8080/)。按 **Ctrl+C** 结束本次运行。

```sh
python scripts/run_library.py --build
```

本机启动器运行四个 Java 业务服务和网页代理。需要运维后端或容器部署时，请按 [Docker 部署说明](deploy/local-identity/README.md) 配置。备份、验证库恢复和主备演示的操作条件见[运维用户手册](docs/E-用户手册-运维.md)。
