# 演示账号对照

数据库用户名不再改拼写。本机口令都是本机 `.env` 里的 `LIBRARY_LOCAL_PASSWORD`。云主机口令由 E 另设。

| 应用账号 | 应用角色 | 数据库登录用户 | 用在哪个服务 | 允许的操作 |
| --- | --- | --- | --- | --- |
| reader01 | 读者 | `db_catalog_reader01` | catalog | 查询书目 |
| reader01 | 读者 | `db_loan_reader01` | loan | 查询自己的借阅，执行借还过程 |
| reader02 | 读者 | `db_catalog_reader02` | catalog | 同 reader01，用于演示换成另一个数据库用户 |
| reader02 | 读者 | `db_loan_reader02` | loan | 同 reader01 |
| librarian01 | 馆员 | `db_catalog_librarian01` | catalog | 维护书目、导入书目 |
| librarian01 | 馆员 | `db_loan_librarian01` | loan | 维护副本、办理借还、执行借还过程 |
| analyst01 | 数据分析员 | `db_report_analyst01` | report | 只查询 report 的四张投影表 |
| sync-bot | 内部同步身份，不能登录页面 | `db_report_sync` | report | 只写入 report 的五张表 |
| 自助注册读者 | 读者（应用层注册，只拿 `READER`） | `db_loan_selfreader` | loan | 查询副本、书目快照与本人借阅，执行借还过程；操作人由事务内的 `reader_id` 指定 |
| 身份服务运行账户 | 无页面角色 | `db_iam_runtime` | iam | 读写登录和映射所需的表 |
| 初始化账户 | 不给业务功能使用 | `gaussdb`，以环境记录为准 | 四个 schema | 只供 D 在空库执行源脚本、导入和导出 |

1. 以上业务账户都不授予 `SYSADMIN`。
2. `analyst01` 不访问 iam、catalog、loan。
3. `sync-bot` 的应用身份由 A 创建，只能调用三条内部读取接口。它在数据库里对应 `db_report_sync`。
4. 自助注册的读者不单独建库角色：注册人数不固定，一人一个角色既难运维，也会把按角色授权的模型冲掉。共享角色 `db_loan_selfreader` 本身没有写权限，借还由 `SECURITY DEFINER` 过程完成；`actor_id()` 只在该角色登录时读取 `library.reader_id`，其他角色读不到也用不上。
5. 浏览器不提交数据库用户名、密码或 schema。`db_identity_mapping` 只保存应用用户、服务名和数据库用户名，不保存数据库口令。口令放在各服务的环境变量里。
