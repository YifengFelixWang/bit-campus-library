# 使用说明：E

- 数据库版本、系统架构、端口和库名见 `00-环境记录.md`。请用同一镜像标签部署，不再另选 openGauss 版本。镜像标签已锁定为 `opengauss/opengauss:7.0.0-RC3.B025-amd64-openEuler22.03`。
- 用这个镜像新建容器时，容器内需要先安装 `openblas`（提供 `libopenblas.so.0`）。这个包不在镜像里，也不在 SQL 备份里。当前这台开发机的容器已经装过。
- 部署时用 `init_roles.py` 创建业务角色，再在空的 `library` 库中导入 `dist/library.sql`。应用运行不使用初始化账户。详细步骤见 `06-重建顺序.md`。
- 导入后请替换云主机上的账户口令。云口令不要写回仓库。本机口令在私有的 `.env`。
- 这份逻辑备份不包含主备复制。主备请在两台数据库节点上另行配置，再做切换演练。
- 封面不在数据库逻辑备份里，清单由 B 提供。
- 这次先交付数据库逻辑备份。备份恢复演练、测试报告统稿和压缩包仍按后续步骤由你负责。
