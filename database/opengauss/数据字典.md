# 数据字典

建表脚本由 D 维护。下表的「写入方」指运行时哪一个服务写这张表。

`book_dim.category_id` 与 `category_dim.category_id` 使用相同编号，两者之间不建外键，也不建指向 `catalog` 的外键。`loan.book_copy.book_id` 只保存 B 生成的图书编号，不建指向 `catalog.book` 的外键。

## iam，由 A 的服务写入

| 表 | 列 | 类型 | 含义 |
| --- | --- | --- | --- |
| app_user | user_id | BIGINT | 用户编号，由 A 生成 |
| app_user | username | VARCHAR(64) | 登录名，唯一 |
| app_user | password_hash | VARCHAR(255) | 密码哈希，由 A 计算，不存明文 |
| app_user | display_name | VARCHAR(100) | 显示名 |
| app_user | enabled | BOOLEAN | 是否可登录 |
| app_user | updated_at | TIMESTAMP | 更新时间 |
| app_user | deleted | BOOLEAN | 停用或删除标记 |
| app_role | role_id | BIGINT | 角色编号 |
| app_role | role_code | VARCHAR(32) | READER、LIBRARIAN、ANALYST、OPERATOR |
| app_role | role_name | VARCHAR(32) | 读者、馆员、数据分析员、运维管理员 |
| user_role | user_id, role_id | BIGINT | 用户与角色的对应 |
| db_identity_mapping | user_id | BIGINT | 应用用户 |
| db_identity_mapping | service_code | VARCHAR(32) | iam、catalog、loan、report |
| db_identity_mapping | db_username | VARCHAR(64) | 该服务使用的数据库登录用户，不存口令 |

## catalog，由 B 的服务写入

| 表 | 列 | 类型 | 含义 |
| --- | --- | --- | --- |
| category | category_id | BIGINT | 分类编号，由 B 生成 |
| category | category_name | VARCHAR(100) | 分类名 |
| category | updated_at / deleted | TIMESTAMP / BOOLEAN | 同步用的更新时间和删除标记 |
| book | book_id | BIGINT | 图书编号，由 B 生成 |
| book | isbn | VARCHAR(32) | ISBN，唯一 |
| book | title | VARCHAR(200) | 书名 |
| book | category_id | BIGINT | 所属分类，外键在 catalog 内 |
| book | updated_at / deleted | TIMESTAMP / BOOLEAN | 同步用 |
| author | author_id | BIGINT | 作者编号，由 B 生成 |
| author | author_name | VARCHAR(100) | 作者名 |
| author | updated_at / deleted | TIMESTAMP / BOOLEAN | 同步用 |
| book_author | book_id, author_id | BIGINT | 书与作者的对应 |
| media | media_id | BIGINT | 封面记录编号 |
| media | book_id | BIGINT | 对应图书 |
| media | file_url | VARCHAR(500) | 封面文件地址。文件本身由 B 放在持久化目录 |
| media | updated_at / deleted | TIMESTAMP / BOOLEAN | 同步用 |

## loan，由 C 的服务写入

| 表 | 列 | 类型 | 含义 |
| --- | --- | --- | --- |
| borrower_account | user_id | BIGINT | 与 iam 的 user_id 相同，不建跨 schema 外键 |
| borrower_account | max_loan_count | INTEGER | 借阅上限，默认 5 |
| borrower_account | active | BOOLEAN | 是否允许借阅 |
| borrower_account | updated_at | TIMESTAMP | 更新时间 |
| book_copy | copy_id | BIGINT | 实体副本编号，由 C 生成 |
| book_copy | book_id | BIGINT | 书目编号，只保存数值 |
| book_copy | barcode | VARCHAR(64) | 条码，唯一 |
| book_copy | status | VARCHAR(32) | AVAILABLE 或 BORROWED |
| book_copy | updated_at | TIMESTAMP | 更新时间 |
| book_snapshot | book_id | BIGINT | 借还页显示用的书目副本 |
| book_snapshot | title / isbn | VARCHAR | 显示用书名和 ISBN，由 C 写入 |
| book_snapshot | updated_at | TIMESTAMP | 更新时间 |
| loan_record | loan_id | BIGINT | 借阅单编号，由 C 生成 |
| loan_record | user_id / copy_id / book_id | BIGINT | 读者、副本、书目 |
| loan_record | status | VARCHAR(32) | BORROWED 或 RETURNED |
| loan_record | borrowed_at / due_at / returned_at | TIMESTAMP | 借出、应还、归还时间 |
| loan_record | updated_at / deleted | TIMESTAMP / BOOLEAN | 同步用 |
| request_dedup | request_no | VARCHAR(64) | 幂等请求号 |
| request_dedup | user_id / operation_type / copy_id / loan_id | 见脚本 | 这次请求对应的操作和业务参数 |
| request_dedup | created_at | TIMESTAMP | 写入时间 |
| loan_audit | audit_id | BIGSERIAL | 数据库生成，不给其他服务引用 |
| loan_audit | loan_id / old_status / new_status | 见脚本 | 触发器写下的状态变化 |
| loan_audit | operator_user_id / request_no / created_at | 见脚本 | 操作者、请求号和时间 |

## report，由 D 的服务写入

投影表之间不建外键。

| 表 | 列 | 类型 | 含义 |
| --- | --- | --- | --- |
| category_dim | category_id / category_name | BIGINT / VARCHAR | 从 B 同步的分类 |
| book_dim | book_id / title / isbn / category_id / author_names | 见脚本 | 从 B 同步的书目。作者名拼成一个字符串 |
| reader_dim | user_id / display_name / role_code | 见脚本 | 从 A 同步的读者显示名 |
| loan_fact | loan_id / user_id / book_id / copy_id / status / 三个时间 | 见脚本 | 从 C 同步的借阅事实 |
| 各投影 | source_updated_at / synced_at / deleted | TIMESTAMP / BOOLEAN | 源端更新时间、写入报表的时间、删除标记 |
| sync_checkpoint | source_name | VARCHAR(32) | iam、catalog、loan |
| sync_checkpoint | cursor_updated_at / cursor_id | TIMESTAMP / BIGINT | 已经成功写入的进度 |
| sync_checkpoint | last_success_at / last_error / status | 见脚本 | 上次成功时间、错误和状态。手工种子的状态是 SEED |
